description: "How to start contributing to open source without frustrating yourself or the maintainers, and what to expect if you publish your own library."
---

One article, written from experience: going from user to contributor to co-maintainer of Marten, a .NET library. If you want to contribute, it tells you how to start small, find your place in the community and work well with maintainers. If you want to publish your own library, it covers what keeps users around, like documentation and a stable API, and why you shouldn't expect to earn money from it.
