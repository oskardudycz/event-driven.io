Trzy praktyczne artykuły, po angielsku. Pierwszy używa nagłówka HTTP ETag, żeby dwie osoby edytujące ten sam rekord nie nadpisywały sobie po cichu zmian. Dwa pozostałe dotyczą danych aktualizowanych chwilę po zapisie: jak utrzymać poprawne read modele w MongoDB i jak sprawić, żeby API chwilę poczekało, a klient zobaczył swoją zmianę.
