---

Jeśli Java kojarzy ci się z rozwlekłymi klasami pełnymi getterów, te dwa artykuły (po angielsku) pokazują, jak wiele się zmieniło. Oba używają koszyka zakupowego zbudowanego z Event Sourcingiem. Pierwszy modeluje decyzje biznesowe rekordami i pattern matchingiem z Javy 22, więc kompilator wskaże pominięte przypadki. Drugi pokazuje, jak własnym kolektorem strumieni odtworzyć bieżący stan z listy zdarzeń.
