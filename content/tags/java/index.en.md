description: "Java has changed a lot in recent versions. Two articles show how its newer features help you write business logic that's shorter and checked by the compiler."
---

If your picture of Java is verbose classes full of getters, these two articles show how much has changed. Both use a shopping cart built with Event Sourcing. The first models business decisions with records and pattern matching from Java 22, so the compiler points out cases you've missed. The second shows how to rebuild the current state from a list of events with a custom stream collector.
