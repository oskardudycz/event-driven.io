description: "Praktyczne przepisy na budowanie, uruchamianie i testowanie aplikacji z Dockerem, Docker Compose i GitHub Actions."
---

Przepisy krok po kroku z prawdziwych projektów, po angielsku. Dowiesz się, jak zbudować mały, wydajny obraz Dockera, zbudować go i opublikować w GitHub Actions, zestawić powiązane kontenery w Docker Compose i jego profilach, uruchamiać testy integracyjne w CI i postawić NGINX przed kilkoma instancjami API. Większość przykładów jest w .NET i Node.js.
