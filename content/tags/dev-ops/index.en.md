---
description: "Practical recipes for building, running and testing applications with Docker, Docker Compose and GitHub Actions."
---

Step-by-step recipes from real projects. You'll find how to build a small, efficient Docker image, build and push it with GitHub Actions, set up related containers with Docker Compose and its profiles, run integration tests in a CI pipeline, and put NGINX in front of several instances of an API. Most examples use .NET and Node.js.
