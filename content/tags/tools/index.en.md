description: "When a documentation site's built-in search isn't good enough. How to set up hosted search with Algolia and keep its index up to date automatically."
---

One article, from documentation work at Event Store. The documentation site's built-in search was too basic, so the team switched to Algolia, a hosted search service. The article shows how to configure crawling the site, run the crawler in Docker and trigger it from GitHub Actions, so the search index updates without anyone having to remember it.
