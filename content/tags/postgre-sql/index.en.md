description: "PostgreSQL handles more than most teams ask of it. See what it can do beyond plain tables, what can be built on top of it, and one timing trap in transactions."
---

Four articles. The first takes a fleet-management system and shows how far PostgreSQL and its extensions go: time-series data, geolocation and pushing changes to a web app. Two announce tools built on it: Pongo, a document database with the MongoDB API and Postgres transactions underneath, and an Event Sourcing store for Node.js. The newest explains why now() doesn't return the current time inside a transaction, and the bug that caused.
