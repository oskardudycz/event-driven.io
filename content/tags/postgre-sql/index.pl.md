Cztery artykuły po angielsku. Pierwszy na przykładzie systemu do zarządzania flotą pokazuje, jak daleko sięgają PostgreSQL i jego rozszerzenia: dane czasowe, geolokalizacja i wysyłanie zmian do aplikacji webowej. Dwa zapowiadają narzędzia zbudowane na Postgresie: Pongo, bazę dokumentową z API MongoDB i transakcjami Postgresa pod spodem, oraz event store dla Node.js. Najnowszy wyjaśnia, dlaczego now() w transakcji nie zwraca bieżącego czasu i jaki błąd z tego wyniknął.
