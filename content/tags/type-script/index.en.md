The older articles are about the type system, especially if you come from C# or Java: why TypeScript compares the shape of objects instead of their declared types, and how `Partial<Type>` lets you build an object step by step without casting. The newer ones come from building Pongo, a library that offers the MongoDB API on top of PostgreSQL. One more shows how to check that a package you publish works in the projects that install it.
