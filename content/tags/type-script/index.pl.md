Artykuły są po angielsku. Starsze dotyczą systemu typów, zwłaszcza jeśli przychodzisz z C# albo Javy: dlaczego TypeScript porównuje kształt obiektów, a nie zadeklarowane typy, i jak `Partial<Type>` pozwala budować obiekt krok po kroku bez rzutowania. Nowsze powstały przy budowie Pongo, biblioteki, która daje API MongoDB na PostgreSQL. Jeszcze jeden pokazuje, jak sprawdzić, czy publikowana paczka działa w projektach, które ją instalują.
