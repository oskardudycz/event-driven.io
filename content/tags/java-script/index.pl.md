Dwa artykuły z różnych epok. Nowszy, po angielsku, dotyczy problemu, na który prędzej czy później trafisz: JSON nie zna dat ani BigInt, więc data wraca jako string, a BigInt rzuca błędem. Pokazuje, jak dodać jawne mapowanie w obie strony. Starszy, z 2015 roku, opisuje loader, który w Knockout.JS sam wczytuje widok i viewmodel komponentu według konwencji nazw, zamiast rejestrować je ręcznie.
