Dwa wpisy z 2015 roku. Pierwszy pokazuje pułapkę w T-SQL: EXISTS sprawdza tylko, czy podzapytanie zwróciło jakiś wiersz, a nie co w nim jest, więc nawet SELECT NULL daje prawdę. Drugi opisuje, jak programista .NET może rozwijać bazę MSSQL w Visual Studio dzięki SQL Server Data Tools: bez ręcznie pisanych skryptów zmian, z prostszymi wdrożeniami i porządną strukturą projektu.
