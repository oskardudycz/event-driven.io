# Open Sans assets

Open Sans version 1.10, digitized data copyright 2010–2011 Google Corporation; Apache License 2.0 (LICENSE.fonts). The original font name table identifies this version and license.

Latin Extended additions are vendored from @fontsource/open-sans 4.0.0 (Google Fonts v18, https://registry.npmjs.org/@fontsource/open-sans/-/open-sans-4.0.0.tgz). Its Latin WOFF2 files are byte-identical to the existing bundled files. Normal and italic weights 300/400/600/700/800 use matching subsets in WOFF2 and WOFF formats. No runtime CDN request or package dependency is required.

CSS Unicode ranges select matching basic/extended files automatically. Local OS font overrides are omitted so different installed font versions cannot mix with self-hosted glyphs. Display sizes, weights and font-display swap remain.
